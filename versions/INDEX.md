# 迭代记录 / Iteration record

> 本文件夹按时间顺序记录**几何结构**的演变，每行一句话描述结构本身。
> 所有图片由各自的设计文件（纯文本 sketch）渲染，与仿真模型同源。
> **本仓库只记录结构形态，不讨论各版本的取舍原因。**
